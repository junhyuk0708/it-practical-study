# 정보처리기사 실기 서재 — CBT 버전

2020~2026년 실기 복원 문제, 족보 1~3탄, Python·Java·C/C++ 문제, 공부 방법을 한곳에서 보는 정적 학습 사이트입니다.

## GitHub Pages에 올리기

1. ZIP을 압축 해제합니다.
2. GitHub 계정 `junhyuk0708`에서 새 공개(Public) 저장소 `it-practical-study`를 만들거나, 사용할 정처기 전용 저장소를 선택합니다. 기존 다른 학습 사이트 저장소의 루트에 섞어 올리지 마세요.
3. 압축을 푼 **파일과 assets 폴더 전체**를 저장소 최상위에 업로드합니다. 저장소 첫 화면에서 `index.html`이 바로 보여야 합니다. ZIP 파일 자체를 올리는 방식은 아닙니다.
4. 저장소 **Settings → Pages → Build and deployment**로 이동합니다.
5. Source를 **Deploy from a branch**, Branch를 **main**, 폴더를 **/(root)**로 선택하고 **Save**합니다.
6. Pages 화면에 표시되는 주소로 접속합니다. 위 이름으로 만들면 예상 주소는 `https://junhyuk0708.github.io/it-practical-study/`입니다. 실제 배포 완료 주소는 Pages 화면에서 확인하세요.

계정 홈페이지용 저장소(`사용자명.github.io`)에 올릴 때도 파일을 최상위에 넣으면 됩니다. 기존 저장소를 사용하는 경우에는 기존 index.html을 덮어쓰기 전에 필요한 파일을 보관하세요.

별도의 npm 설치, 빌드, API 키, 서버는 필요 없습니다. 파일 경로는 상대 경로여서 프로젝트 하위 경로에서도 동작하도록 구성했습니다.

GitHub 공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

### 시나공 대조 1차 승인 반영

2026-10-20 사용자 승인에 따라 다음 3개 주제를 4곳에 반영했습니다.

- 논리적 설계: 목표 DBMS가 지원하는 논리 구조로 변환한다는 설명을 족보 1·2탄에 추가했습니다(핵심요약 16쪽).
- UML 구조 다이어그램: 교재 수록 6종과 프로파일 보충 설명을 분리했습니다. 기존 프로파일 추가 기록은 오류 정정이 아닌 범위 보충으로 정정했습니다(7쪽).
- 교착상태: 네 가지 필요조건을 유지하고 순환 대기(환형 대기)를 병기했습니다. 자원 인스턴스 개수에 따른 판단 전제를 보완했습니다(115쪽).

이 반영은 위 3개 주제에 한정하며 기출 전 문항의 시나공 대조 완료를 뜻하지 않습니다. 교재 PDF와 이미지 원본은 배포 파일에 포함하지 않습니다.

## 사용 방법

`index.html`을 브라우저로 열거나 GitHub Pages 주소에 접속합니다. 기출 또는 언어별 자료를 선택하면 한 문제씩 표시됩니다. 「내 답안」에 답을 입력하고 「정답 확인」으로 비교하세요. 이전·다음 버튼이나 문제 번호로 이동할 수 있으며, 자료에 다시 들어오면 마지막 문제부터 이어집니다. 정답을 확인해도 완료로 자동 처리하지 않으므로 직접 「학습 완료 표시」를 눌러주세요. 「현재 문제 인쇄」는 현재 문항과 펼친 해설을 인쇄합니다. 개념 정리와 학습 가이드는 전체 본문을 이어서 읽는 방식입니다.

학습 완료·별표·입력한 답안·마지막 위치는 해당 브라우저에 저장됩니다. 다른 기기나 주소로 이동할 때는 「기록 백업」으로 JSON 파일을 저장한 뒤 「불러오기」를 이용하세요. 불러오기는 기존 기록에 완료·별표 기록을 합치고, 현재 비어 있는 답안만 백업 답안으로 보완합니다. 자동 채점 기능은 없습니다.

## 파일

- `index.html`: 사이트 진입점
- `style.css`: 화면 디자인과 모바일·인쇄 스타일
- `app.js`: 검색, 이동, 정답 토글 보조, 학습 기록
- `data.js`: 전체 학습 본문과 수정 기록
- `assets/`: 원문 문제 그림
- `sources.json`: 자료별 출처, 라이선스, 변경 내역
- `code-verification.json`: 언어별 예제 실행 결과
- `exam-fix-verification.json`: 수정 및 누락 답안 보완 기출의 실행 결과
- `ATTRIBUTION.md`: 저작자표시 및 편집 범위

현재 묶음의 릴리즈는 `2026-10-20.5-final`입니다. 전체 기출에 대한 공식 답안 대조 완료를 뜻하는 표시는 아닙니다.

본문을 추가 수정하려면 `data.js`의 자료별 `blocks[].html`을 수정하고 변경 사항을 `corrections`와 `sources.json`에도 남기면 됩니다. 학습 진도 유지가 필요하면 기존 블록의 id와 data-unit 값을 유지하세요.
